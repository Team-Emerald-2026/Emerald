# 仕様変更メモ

## 2026-08-22 方針

### 来場者向け
- モバイルオーダーと予約システムは一旦なくし、注文タブはカミングスーンまたは呼び出し番号確認画面として扱う。
- 下部ナビは `ホーム` / `ブース` / `注文(呼び出し番号)` / `イベント(お知らせ)` / `マップ` の5項目に変更予定。
- ブース詳細には、店舗名、説明、メニュー一覧、場所(マップリンク)、電子呼び出し番号、一人あたりの待ち時間を表示する。
- `/attractions` の「注文対象外」表示は削除する。
- `/attractions` の「人気」の定義を決める。現状は待ち人数または待ち時間ベースの暫定判定。
- 待ち時間が短いブースをクリックしたとき、該当ブースの詳細が自動で開き、画面中央に来るようにする。
- マップのフィルタは削除する。マップは校内図画像とブースピンを中心にする。
- イベントまたはお知らせ画面を追加する。

### 店舗向け
- 当日は飲食店舗に iPad、体験店舗にノート PC を支給する想定。
- 店舗側で紙媒体の決済合計と突き合わせられるよう、当日アプリ内でも売上を記入できるようにする。
- 電子呼び出し番号は作成する。
- 本番校内モニターに、呼び出し番号一覧を表示する画面を作成する。
- 時間で開始するブースは、待ち時間入力をチェックボックスでテキストボックス入力に切り替えられるようにする。
- `/store/login` の「初めての方は 新規登録」を削除する。
- `/store/login` から `/admin` に入れるようにする。
- `/store/profile` はログイン情報がなく閲覧できない不具合を修正する。
- `/store/dashboard` に総収益の表示を追加する。
- `/store/served` に編集・削除ボタンを追加する。

### 管理画面
- `/admin` を追加する。
- 管理画面では新規店舗の作成、総収益の表示、各店舗情報の閲覧・削除・編集を行う。
- 集めたデータを集積、分析、可視化する。

## 現在入っている主な変更
- フロントエンドは React + Vite 構成。
- 来場者向けのブース、ホームおすすめ、マップはバックエンド API から店舗・施設データを取得する。
- 校内マップは `frontend/public/campus-map-1f.png` から `campus-map-8f.png` のフロア画像を使用する。
- ホームのヒーローは `frontend/public/hero.mp4` を使用する。
- 店舗ログイン、ログアウト、ダッシュボード、会計メニュー、会計注文、清算 API が追加済み。
- 店舗登録画面 `/store/register` と店舗情報画面 `/store/profile` が追加済み。
- 受付番号は `stores.ticket_prefix` と `ticket_counters` により、店舗ごとに `C-101` のような形式で採番する。
- OpenAPI 仕様 `docs/openapi.yml` と API 計測用 `frontend/tests/apitest.js` が追加済み。
